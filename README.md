# My Dashboard

내 컴퓨터에서 실행하는 1인용 웹 대시보드입니다. 대시보드를 열면 **오늘 할 일, 다가오는 일정, 진행 중인 프로젝트**가 바로 보이고, GPT에게 우선순위를 묻거나 대화로 일정·할 일을 등록할 수 있습니다.

- 데이터는 내 컴퓨터의 SQLite 파일 하나(`data/dashboard.db`)에 저장됩니다.
- 기본 시간대는 `Asia/Seoul` 입니다.
- 외부 패키지 설치가 필요 없습니다. Node.js만 있으면 됩니다 (`npm install` 불필요).

## 1. 준비물

**Node.js 22.13 이상** (22 LTS 권장). 설치되어 있는지 확인:

```sh
node -v     # v22.13.0 이상이면 OK
```

없다면 https://nodejs.org 에서 LTS 버전을 설치하세요.
(Node 22에 SQLite가 내장되어 있어서 따로 DB를 설치할 필요가 없습니다.)

## 2. 실행

```sh
git clone https://github.com/red-crypto/Web-Dashboard.git
cd Web-Dashboard
npm start
```

브라우저에서 **http://localhost:3000** 을 엽니다. 끝내려면 터미널에서 `Ctrl+C`.

API 키가 없어도 할 일·일정·프로젝트 기능은 모두 동작합니다. AI 채팅만 비활성 상태가 됩니다.

## 2-1. 더 편하게: 바탕화면 아이콘 + 자동 실행

한 번만 설치하면 그다음부터는 **바탕화면의 `My Dashboard` 아이콘을 더블클릭**하면 됩니다. 아이콘을 누르면 서버가 창 없이 켜지고 브라우저가 열립니다. 서버가 이미 켜져 있으면 브라우저만 열립니다.

설치할 때 "컴퓨터를 켤 때 자동 실행"을 고르면, 부팅/로그인할 때 서버가 미리 켜집니다. 그러면 브라우저 즐겨찾기에 `http://localhost:3000` 을 넣어 두고 바로 열 수도 있습니다.

**Windows**

1. 탐색기에서 `launcher\windows\install.bat` 를 더블클릭합니다.
2. 자동 실행 여부를 `Y` / `N` 으로 답합니다.
3. 바탕화면에 `My Dashboard` 아이콘이 생깁니다.

**macOS**

1. Finder에서 `launcher/mac/install.command` 를 더블클릭합니다. ("확인되지 않은 개발자" 경고가 뜨면 우클릭 → 열기)
2. 자동 실행 여부를 `y` / `n` 으로 답합니다.
3. 바탕화면에 `My Dashboard` 아이콘이 생깁니다.

> macOS에서 자동 실행을 쓰려면 저장소를 `~/Desktop`, `~/Documents`, `~/Downloads` **밖**(예: `~/Web-Dashboard`)에 두세요. 이 폴더들은 macOS 보호 정책 때문에 자동 실행된 서버가 파일을 읽지 못할 수 있습니다.

**서버 끄기**: 대시보드 **설정** 화면 맨 아래의 `서버 종료` 버튼. 다시 켜려면 아이콘을 누르면 됩니다.
**지우기**: `launcher/windows/uninstall.bat` 또는 `launcher/mac/uninstall.command` 실행 (데이터는 그대로 남습니다).
**문제가 생기면**: 창 없이 실행된 서버의 로그는 `data/server.log` 에 쌓입니다. 창을 띄워서 직접 보고 싶으면 Windows는 `launcher\windows\start.bat`, macOS/Linux는 `npm start` 로 실행하세요.

저장소 폴더를 다른 곳으로 옮겼다면 install 스크립트를 한 번 더 실행해 주세요 (아이콘이 이전 경로를 가리키기 때문).

## 3. API 키 설정 (AI 채팅용)

OpenAI API 키는 **서버(내 컴퓨터)에서만** 읽고 브라우저로는 보내지 않습니다.

```sh
cp .env.example .env      # Windows: copy .env.example .env
```

`.env` 파일을 열어 키를 넣고 서버를 다시 실행합니다.

```
OPENAI_API_KEY=sk-...
```

`.env` 는 `.gitignore` 에 들어 있어 git에 올라가지 않습니다. 앱의 **설정** 화면에서 `연결 테스트` 를 눌러 확인할 수 있습니다.

선택 설정 (`.env` 에 추가):

| 변수 | 기본값 | 설명 |
|---|---|---|
| `OPENAI_MODEL` | `gpt-4o-mini` | 기본 모델 (앱 **설정** 화면에서 바꾼 모델이 우선) |
| `PORT` | `3000` | 접속 포트 |
| `APP_TIMEZONE` | `Asia/Seoul` | '오늘', '이번 주' 계산 기준 |
| `DB_PATH` | `data/dashboard.db` | DB 파일 위치 |
| `HOST` | `127.0.0.1` | 기본값은 내 컴퓨터에서만 접속 가능 |

## 4. 화면 구성

| 메뉴 | 내용 |
|---|---|
| 홈 | 인사말과 날짜, 통계 3개(하루 진행률 · 완료 시간 · 기록 시간), **오늘 일정 타임라인**(시간 블록, 빈 시간을 누르면 추가, 동그라미로 완료, ▶ 로 타이머), 오른쪽에 확인 필요(체크 없이 지난 블록, 기한 지난 할 일) · 현재 집중(타이머) · 다음 블록과 `시작` · 오늘 할 일 · 오늘 습관. `미룬 일 가져오기` 는 기한 지난 할 일을 오늘로 옮김 |
| 프로젝트 | 목표·마감일·진행률. 프로젝트를 열면 **다음에 할 작업**이 맨 위에 보임 |
| 할 일 | `오늘` · `이번 주` · `예정` · `완료` 필터, 목록에서 바로 체크, 항목을 누르면 수정 |
| 일정 | 월간 캘린더에 일정과 할 일 마감일을 함께 표시. 날짜를 누르면 그날 목록이 오른쪽에 펼쳐짐 |
| AI 채팅 | 이전 대화 목록과 채팅. 다른 화면에서는 우측 상단 `AI 열기` 로 옆에 띄워서 사용 |
| 설정 | API 연결 상태, 시간대, DB 파일 위치 |

사이드바의 `새 할 일`(단축키 `N`)과 `검색`(단축키 `Ctrl+K`, Mac은 `⌘K`)은 어느 화면에서나 쓸 수 있습니다. 시간 블록은 일정 중 시작 시간이 있는 항목이라, 캘린더와 같은 데이터입니다.

### AI 채팅 사용법

채팅 상단의 **참고 범위**(`오늘 할 일` / `현재 프로젝트` / `전체`)에 있는 데이터만 GPT에게 전달됩니다. 프로젝트 화면에서 `AI 열기` 를 누르면 그 프로젝트가 기본 선택됩니다.

- `현재 프로젝트`: 그 프로젝트의 목표·할 일·일정만 보냅니다. 다른 프로젝트 정보는 보내지 않습니다.
- `오늘 할 일`: 지연·오늘·7일 내 할 일과 7일 내 일정만 보냅니다.
- `전체`: 프로젝트 목록과 미완료 할 일 전체, 30일 내 일정을 보냅니다.
- 같은 대화에서 범위를 바꾸면 **이전 대화는 보내지 않습니다** (같은 범위로 이어진 최근 대화만 최대 20개). 필요하면 입력창 위의 `이전 대화도 함께 보내기` 를 체크하세요.
- 모델은 **설정 → 모델**에서 바꿉니다. `내 키로 쓸 수 있는 모델 불러오기` 로 목록을 받거나 이름을 직접 입력하세요.
- OpenAI **Responses API**(`/v1/responses`)로 호출하므로 추론 모델(예: gpt-6 계열)도 일정·할 일 등록 도구를 쓸 수 있습니다. `store: false` 로 보내 OpenAI 쪽에 대화가 저장되지 않게 합니다. `/responses` 를 지원하지 않는 OpenAI 호환 서버(`OPENAI_BASE_URL`)는 자동으로 Chat Completions 로 호출합니다.

- "오늘 뭐부터 할까?" → 지연 항목, 오늘 마감, 가까운 일정을 보고 순서와 이유를 정리
- "이 프로젝트 다음에 뭘 해야 해?" → 프로젝트 목표와 남은 할 일로 다음 작업 제안
- "내일 오후 3시에 프로젝트 회의 등록해줘." → 제목·날짜·시간 **미리보기 카드**가 나오고, `등록` 을 눌러야 저장됨 (할 일 추가도 동일)

`등록` 을 여러 번 눌러도 한 건만 만들어집니다. API 오류가 나면 입력한 메시지는 입력창에 그대로 남고 `재시도` 버튼이 표시됩니다.

## 5. 데이터 백업

`data/dashboard.db` 파일 하나가 전부입니다. 서버를 끈 상태에서 이 파일을 복사하면 백업, 덮어쓰면 복원입니다.

## 6. 테스트

```sh
npm test
```

가짜 OpenAI 서버를 띄워 실제 키 없이 다음을 확인합니다: 저장/수정 후 홈 숫자와 진행률 갱신, 마감일 수정의 캘린더 반영, 우선순위 질문에 오늘 데이터가 전달되는지, `등록` 을 5번 동시에 눌러도 일정 1건만 생성, API 오류 시 아무것도 저장되지 않는지.

## 7. 코드 구조

빌드 단계가 없습니다. 파일을 고치고 서버를 재시작(브라우저는 새로고침)하면 바로 반영됩니다.

```
server/
  server.js   HTTP 서버, API 라우팅, 정적 파일 제공 (진입점)
  db.js       SQLite 테이블 정의와 모든 쿼리, 입력 검증
  ai.js       OpenAI 호출, 참고 범위별 컨텍스트 생성, 등록 제안(tool call) 처리
  focus.js    홈 요약, 타이머/시간 기록, 습관, 검색, 미룬 일 가져오기
  time.js     Asia/Seoul 기준 날짜 계산
public/
  index.html  화면 뼈대 (사이드바, 상단바, AI 드로어)
  styles.css  디자인 (차콜 배경 + 시안 포인트)
  app.js      화면 렌더링과 이벤트 처리 (프레임워크 없음)
  home.js     홈 화면 (타임라인, 타이머, 습관)
test/
  api.test.js API 통합 테스트
launcher/
  windows/    install.bat · uninstall.bat · start.bat(창 띄워 실행) · start-hidden.vbs(창 없이 실행)
  mac/        install.command · uninstall.command · start-dashboard.command
```

`node server/server.js --open` 으로 실행하면 서버가 뜬 뒤 브라우저를 엽니다. 이미 실행 중이면 브라우저만 열고 바로 끝납니다. 아이콘은 이 옵션을 씁니다.

데이터 흐름은 단순합니다: 브라우저(`app.js`) → `fetch('/api/...')` → `server.js` 라우트 → `db.js` 함수 → SQLite. 채팅만 `ai.js` 를 거쳐 OpenAI를 호출합니다.

DB 테이블: `projects`, `todos`, `events`, `conversations`, `messages`, `proposals`(채팅에서 나온 등록 제안. `pending` 상태일 때만 실제로 저장되므로 중복 생성이 막힘). `time_logs`(타이머·직접 기록), `habits`·`habit_checks`(습관), `settings`(선택한 모델 등). 기존 DB 파일은 서버를 켤 때 자동으로 새 테이블·컬럼이 추가됩니다.
